# Project Context: Atlas Educational Society Website

- Next.js project for the Atlas Educational Society (Alberta Societies Act non-profit).
- Built with React 19 and Next.js 16 (Turbopack).
- Minimalist, privacy-first software society design suitable for Apple Developer Program organization enrollment.
- Board of Directors section intentionally omitted to protect family privacy; focus is on mission, commitments, and software portfolio.
- Software Portfolio showcases:
  - Atlas Calculator (STEM live calculation scratchpad with units and stacked fractions).
  - UAlberta Campus Map Studio (True SVG vector cartography & sub-zero heated pedway navigation).
  - UAlberta Open Student Hub (Native iOS client with persistent SSO and digital OneCard).
  - Typery (Adaptive touch typing tutor and literature reader).
- Registered address is hidden for privacy; only the city (Fort Saskatchewan) is listed.
